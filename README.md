# Botium Toys – Internal Security Audit

## Overview

This project documents an internal security audit and risk assessment
for Botium Toys, a fictional retail organization.

The purpose of the audit was to evaluate the organization's security
controls, compliance practices, identify security risks, and provide
recommendations to improve its overall security posture.

## Objectives

- Identify organizational assets
- Assess existing security controls
- Evaluate compliance practices
- Identify security risks and weaknesses
- Recommend security improvements

## Scope

The audit covered:

- Employee devices and equipment
- Internal network
- IT systems
- Data storage
- Security controls
- Physical security
- Compliance practices

## Risk Assessment

**Risk Score: 8/10 – Fairly High**

The assessment identified several security weaknesses, including:

- Lack of least privilege
- Lack of separation of duties
- No encryption for sensitive customer information
- No intrusion detection system (IDS)
- No disaster recovery plan
- No backup of critical data
- No centralized password management system
- Weak password requirements
- Inadequate asset management
- Legacy system maintenance weaknesses

## Compliance Assessment

### PCI DSS

Key gaps identified:

- Unauthorized access to sensitive cardholder information
- Lack of encryption
- Weak password management
- Insufficient access controls

### GDPR

Key findings:

- EU customer data protection requires improvement
- 72-hour breach notification plan exists
- Data classification and inventory require improvement
- Privacy policies and procedures are established

### SOC

Key findings:

- User access controls require improvement
- PII/SPII confidentiality requires improvement
- Data integrity controls are established
- Data availability controls are established

## Recommendations

Priority recommendations include:

1. Implement least privilege.
2. Implement separation of duties.
3. Encrypt sensitive customer and payment information.
4. Deploy an intrusion detection system.
5. Implement regular backups.
6. Develop a disaster recovery plan.
7. Implement centralized password management.
8. Strengthen password requirements.
9. Establish regular legacy-system maintenance.
10. Improve asset classification and inventory.
